# NeuroSim AI Product Demo Videos — Design Spec

**Date:** 2026-05-20
**Status:** Approved by user
**Format:** Remotion (React-based video)

---

## Overview

Three product demo videos for NeuroSim AI, each serving a distinct distribution channel:

1. **Landing Page Hero** (30-60s) — Loops on neurosimai.vercel.app
2. **Product Tutorial** (2-3 min) — Educational walkthrough for new users
3. **Social Media Teaser** (15-30s) — Scroll-stopping content for X/LinkedIn/TikTok

All videos share the NeuroSim brand: dark theme, purple/blue gradient accents, clean modern typography.

---

## Video 1: Landing Page Hero (30-60s)

### Purpose
Visually striking hero video for the landing page. Communicates core value prop instantly. Designed to loop seamlessly.

### Structure

| Time | Section | Content |
|------|---------|---------|
| 0-5s | Hook / Problem | "What if you could predict how your content performs... before you film it?" + neural network particles |
| 5-15s | The Reveal | "Meet NeuroSim AI" + logo + tagline + 4 ROI badges flash |
| 15-30s | How It Works | "Paste your script" → scores animate → "Stage-Gate PASS" |
| 30-45s | Engines | Split: "TRIBE v2 Neural Encoding" | "MiroFish Swarm Simulation" + swarm dots |
| 45-60s | CTA | "10 analyses/month · No credit card" + "Start Predicting →" + URL |

### Technical
- Resolution: 1920x1080 (16:9)
- FPS: 30
- Loop: End frame transitions back to opening
- No audio (designed for autoplay)

## Video 2: Product Tutorial (2-3 min)

### Purpose
Walk new users through the actual product flow — from landing page to first analysis results.

### Structure

| Time | Section | Content |
|------|---------|---------|
| 0-10s | Intro | "Welcome to NeuroSim AI" + overview |
| 10-30s | Getting Started | Landing page → Dashboard → "Free account, no credit card" |
| 30-60s | Script Analysis | Paste script → Analyze → "Heuristic scoring, instant results" |
| 60-100s | ROI Results | Walk through A5, LO, Area45, TPJ scores + Stage-Gate PASS |
| 100-140s | Swarm Simulation | MiroFish visualization → viral coefficient, sentiment, backlash |
| 140-160s | Comparison | Benchmark comparison + what-if simulation mention |
| 160-180s | Video Analysis + Wrap | Upload flow mention + "10 free analyses" + URL |

### Technical
- Resolution: 1920x1080 (16:9)
- FPS: 30
- Screen-capture style with UI mockups
- Cursor animations showing clicks
- Callout annotations highlighting key elements

## Video 3: Social Media Teaser (15-30s)

### Purpose
Punchy, scroll-stopping content optimized for social platforms. Grabs attention in first 2 seconds.

### Structure

| Time | Section | Content |
|------|---------|---------|
| 0-2s | Hook | "Stop guessing if your content will work." + zoom-in |
| 2-8s | Twist | "What if you could PREDICT it?" + ROI scores flash |
| 8-15s | Product | "NeuroSim AI analyzes your script before you film" + quick cut |
| 15-22s | Social Proof | "Neural encoding + 1000-agent swarm" + swarm animation |
| 22-30s | CTA | "10 free analyses. No credit card." + URL + "Try it now →" |

### Technical
- Resolution variants: 1080x1920 (9:16 vertical) + 1080x1080 (1:1 square)
- FPS: 30
- High contrast, bold typography
- Fast cuts (no shot > 3s)
- Text-driven (no voiceover needed for silent autoplay)

---

## Shared Visual Style

- **Background:** Dark (#0a0a0f to #1a1a2e gradient)
- **Primary accent:** Purple (#7c3aed) to Blue (#3b82f6) gradient
- **Typography:** Inter or similar modern sans-serif
- **Animation style:** Smooth easing (ease-in-out), no harsh cuts
- **Logo:** NeuroSim AI branding
- **ROI Badges:** A5, LO, Area45, TPJ with progress bar animations
- **Swarm visualization:** Particle dots converging
